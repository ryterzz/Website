# Ryder

Personal website for Ryder, built with plain HTML and CSS.

## Pages

- Home
- About
- Gaming
- Anime
- Coding
- Music

## Run locally

Open `index.html` in a browser, or start a local server:

```powershell
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).
